# Personal Portfolio Website

A responsive, custom-built personal portfolio website designed to showcase my professional experience, technical skills, and projects in Data Science and Machine Learning. 

This website is automatically built and deployed via Continuous Integration/Continuous Deployment (CI/CD) using **AWS Amplify**.

## 🚀 Live Demo
https://main.d2x0nki42yqjos.amplifyapp.com

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Deployment & Hosting:** AWS Amplify, GitHub
*   **Other Core Technologies I Work With:** Python, Flutter, Machine Learning (TensorFlow/Keras), Data Science libraries (Pandas, Scikit-Learn)

## 📊 Featured Projects Highlighted
*   **Customer Churn Prediction:** An end-to-end predictive analytics model developed during my Data Science internship to identify at-risk customers based on behavioral data.
*   **Handwritten Digit Recognition (CNN):** A Convolutional Neural Network built to classify the MNIST dataset, achieving an evaluation accuracy of 98.86%.
